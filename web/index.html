M5Stack Core2 DeviceRadar

Rotational WiFi + BLE radar. Hold still, turn once, map every signal around you. Offline. No cloud.

1Flash the firmware

Plug your M5Stack Core2 into USB, put it in download mode if needed (hold BtnB while resetting), then hit Install.

Your browser does not support Web Serial. Use Chrome or Edge on desktop. Permission denied — allow serial access when prompted. ESP32 · Core2

2What you get

WiFi Radar Guided 360° sweep maps access points by bearing. Radius = relative RSSI.
BLE Radar Same for Bluetooth LE advertisements. Live map stays room-fixed while you turn.
Gyro heading Gravity-projected yaw — works held flat or upright. No magnetometer needed.
Mantis UI Teal · purple · lime · dark grey. Mascot sits in the centre of every scan.

3On-device controls

BtnA select / rescan  ·  BtnB next menu item  ·  BtnC exit / long-press power off
Touch works too. Hold still for calibration, then keep the green needle on the red one for one full turn.
